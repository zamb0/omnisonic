# Icons Directory

This directory contains custom icons and graphics for the Omnisonic design system.

## Icon Files

### Logo and Branding
- omnisonic_logo.svg - Main application logo (SVG format)
- omnisonic_logo.png - Main application logo (PNG format)

### Music Icons
- music_note.svg - Custom music note icon
- waveform.svg - Audio waveform visualization icon

## Icon Guidelines

- Use SVG format when possible for scalability
- Provide PNG fallbacks for compatibility
- Icons should follow Material Design principles
- Use consistent stroke width and corner radius
- Optimize file sizes for performance

## Placeholder Icons

The design system uses Material Icons as the primary icon set. Custom icons in this directory supplement the Material Icons where needed.
