# Images Directory

This directory contains images and graphics for the Omnisonic design system.

## Image Files

### Placeholder Images
- album_placeholder.png - Default album artwork placeholder
- artist_placeholder.png - Default artist image placeholder
- playlist_placeholder.png - Default playlist image placeholder

### Background Images
- gradient_bg.png - Gradient background for special screens
- music_bg.png - Music-themed background pattern

## Image Guidelines

- Use PNG format for images with transparency
- Use JPEG format for photographic content
- Provide multiple resolutions (@1x, @2x, @3x) when needed
- Optimize file sizes for performance
- Follow accessibility guidelines for contrast and readability

## Placeholder Content

All placeholder images should:
- Be visually appealing and consistent with the design system
- Use the brand color palette
- Be optimized for different screen densities
- Include appropriate alt text for accessibility
