# Fonts Directory

This directory contains the custom fonts for the Omnisonic design system.

## Required Fonts

### Inter Font Family
- Inter-Regular.ttf (weight: 400)
- Inter-Medium.ttf (weight: 500)
- Inter-SemiBold.ttf (weight: 600)
- Inter-Bold.ttf (weight: 700)

### Poppins Font Family
- Poppins-Regular.ttf (weight: 400)
- Poppins-Medium.ttf (weight: 500)
- Poppins-SemiBold.ttf (weight: 600)
- Poppins-Bold.ttf (weight: 700)

## Download Instructions

1. **Inter**: Download from https://fonts.google.com/specimen/Inter
2. **Poppins**: Download from https://fonts.google.com/specimen/Poppins

Extract the TTF files and place them in this directory with the exact names listed above.

## Fallback

If custom fonts are not available, the system will fall back to:
- Roboto (Android)
- San Francisco (iOS)
- System default (Desktop)
