Multi-server Subsonic client

Every server.
One library.

Omnisonic merges every Subsonic-compatible server you own into a single collection, folds duplicate tracks together and streams each song from the best copy that is online right now.

Features

Built for more than one server

  • Many servers, one library

    Navidrome, Gonic, Airsonic and any other Subsonic server. Albums, artists and playlists from all of them, side by side.

  • Duplicates, folded

    The same song on three servers shows up once. Tracks are matched by fuzzy metadata and duration, not just file names.

  • Best copy, always

    Playback picks the highest-quality copy on a server that answers, and switches when one goes down.

  • Offline downloads

    Keep albums and tracks on the device for flights, trains and the basement gym.

  • Lyrics

    Synced lyrics that follow the song when your server provides them, plain text otherwise.

  • At home on every OS

    Lock-screen and notification controls on mobile, MPRIS on Linux, keyboard navigation on desktop.

How it works

Three steps, no migration

  1. 01

    Connect your servers

    Add each server with its URL and account. Passwords stay in the platform's secure storage.

  2. 02

    Sync and merge

    Omnisonic indexes every library locally and groups the tracks that are the same song.

  3. 03

    Press play

    Each server keeps its own files. Omnisonic only decides which copy you hear.
